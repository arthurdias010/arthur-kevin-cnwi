# 📋 Lista com DOM

Este repositório contém o projeto **Lista com DOM**, desenvolvido como atividade prática da disciplina de **Interfaces Web II**. O objetivo é aplicar os conhecimentos de HTML, CSS e JavaScript, utilizando o DOM (Document Object Model) para criar e manipular elementos dinamicamente em uma página web.
